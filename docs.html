Documentation

Everything you need to work with Jott — and with the files it writes, with or without it.

  • File format ↗

    The whole contract: everything Jott knows is in the notebook folder, and everything in there is readable without the app. Enough to write your own tool against a notebook — or to move your notes somewhere else without asking anyone.

  • Theming ↗

    A theme is one CSS file. No build step, no JavaScript — the smallest useful thing you can make for Jott.

  • Architecture ↗

    Three layers, and the split between them is the whole design: a pure Rust core, a thin shell, one interface.

  • Building ↗

    One codebase, three platforms. What you need installed, and what each target expects.

  • Plugins ↗

    There is no plugin API. What is settled, what isn't, and what you can do today instead.

  • Contributing ↗

    Setup, the two test suites, and the handful of rules that keep this codebase the way it is.
