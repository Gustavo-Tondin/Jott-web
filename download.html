Platform File Notes
Linux (any distro) .AppImage chmod +x, then run. Updates itself. To remove, delete the file.
Debian / Ubuntu .deb Installs into the app menu.
Fedora .rpm Same.
Arch PKGBUILD ↗ Build from source: cd packaging/linux && makepkg -sid
Windows .exe Installs for the current user, no admin. Updates itself.
Android .apk Open this page on the phone and tap the file.

First run

Windows

Jott isn't code-signed: Windows shows "Windows protected your PC" — click More info, then Run anyway. Once, per version.

Android

Android asks once to allow installs from your browser. A newer APK installs over the old one and keeps your data.

Linux

The AppImage needs chmod +x before it will run. The .deb and .rpm open in your system's installer.

Updates

Jott checks GitHub once a day for a new version (you can turn this off in Settings — it is the only connection the app ever makes, and it sends nothing about you or your notebook). The AppImage and the Windows build update themselves in place; package-manager installs and the APK get a button that opens the download page. A newer APK installs over the old one and keeps your data.
