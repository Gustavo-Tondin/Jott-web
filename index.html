Questions

Does it sync between devices?

Not by itself, point Syncthing, Drive, Dropbox or git at the notebook folder and it syncs like any folder. An optional, end-to-end encrypted sync may come later.

Where is my data?

In a folder you chose, as .md and .json files. Nowhere else. Jott's only connection is a daily check for new versions, and you can turn that off.

What happens if I stop using Jott?

Nothing. The folder stays where it is, readable in any editor. That's the point.

Is it free?

Yes, and the local app always will be. If paid services ever exist (sync, backup), they'll be optional additions.

Is there an iOS or macOS version?

iOS: there's no free way to distribute there. macOS: not yet, I don't have a Mac to test on. Linux, Windows and Android today.

Why do Windows and Android warn me?

Jott is safe but isn't code-signed yet (that costs money every year). Click More info → Run anyway on Windows, or allow installs from your browser on Android, once per version. The code is open if you'd rather check for yourself.

What does "last seen" record, and where?

Opening a note, or editing it. The date is kept in .jott/index/ locally inside your notebook, never sent anywhere, and rebuildable if you delete it.

Can I install plugins?

For now, it is only safe to install external themes (a single CSS file); plugins with executable code within the app are not supported yet.
